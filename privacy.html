개인정보 처리방침

서비스명 도롱뇽 (강화 RPG) · 운영자 rohghor_RG · 문의 디스코드 DM ryugyeom1122_58763
시행일 2026년 5월 29일 · 최종 수정일 2026년 9월 14일

본 방침은 봇이 어떤 정보를 수집하고, 어떻게 이용·보관·파기하는지를 설명합니다. 봇을 이용함으로써 이용자는 본 방침에 동의하는 것으로 봅니다.

1. 수집하는 정보

봇은 게임 진행에 필요한 최소한의 정보만 수집·저장합니다.

(1) 디스코드 계정 식별 정보

  • 디스코드 사용자 ID (숫자 형태의 고유 식별자)
  • 디스코드 표시 이름(username) — 명령어 사용 시점의 닉네임

(2) 게임 진행 데이터

  • 강화·각성·환생 단계, 가상 재화(게임 머니·은행 잔액), 아이템·룬·펫·칭호 보유 현황
  • 스탯, 전투력, 던전·탑·레이드·PvP 전적, 길드 소속 정보
  • 출석·사망·탐험 등과 관련된 타임스탬프(시간 기록)
  • 이용자가 직접 설정한 커스텀 이름 및 이미지 URL (조력자 커스터마이즈 사용 시)

(3) 이용자가 입력한 텍스트

  • !제작, !신탁 등 AI 연동 명령어 사용 시 이용자가 입력한 설명·질문 텍스트
봇은 이메일, 전화번호, 비밀번호, 결제 정보, 실명 등은 일절 수집하지 않습니다. 또한 현실의 금전 거래가 없습니다.

2. 정보의 수집 방법

  • 이용자가 디스코드에서 봇의 명령어(! 또는 /)를 직접 사용할 때 해당 정보가 생성·저장됩니다.
  • 명령어를 한 번도 사용하지 않은 사용자의 정보는 수집되지 않습니다.

3. 정보의 이용 목적

  • 게임 진행 상태의 저장 및 불러오기 (강화 수치, 재화, 아이템 등)
  • 랭킹·전적·길드 등 게임 기능 제공
  • 부정행위·버그 악용·도배 방지 및 서비스 안정적 운영
  • AI 연동 기능(!제작, !신탁)의 결과 생성

4. 제3자 제공 및 처리 위탁

봇은 이용자의 정보를 판매하지 않으며, 다음의 경우에 한해 외부 서비스가 데이터를 처리합니다.

제공받는 자처리 항목목적
Discord사용자 ID · 메시지 등봇 동작을 위한 메시지 송수신 플랫폼
Anthropic (Claude API)!제작·!신탁 등에 입력한 텍스트AI 텍스트 결과 생성 (해당 명령어 사용 시에만 전송)
Google (Gemini API)유니크 장비 제작 시 생성된 장비 이름·설명 텍스트장비 일러스트 실시간 생성 (해당 기능 사용 시에만 전송)
  • 각 사는 자사의 개인정보 처리방침에 따라 데이터를 처리합니다.
  • 이용자는 AI 명령어에 개인정보·민감정보를 입력하지 않아야 합니다.

5. 정보의 보관 및 파기

  • 게임 데이터는 운영자가 관리하는 서버(호스팅 환경)의 데이터 파일 형태로 저장됩니다.
  • 데이터는 이용자가 게임을 이용하는 동안 보관되며, 다음의 경우 파기됩니다.
    • 이용자가 삭제를 요청한 경우
    • 운영자가 데이터 초기화·리셋을 수행한 경우
    • 서비스 종료 시

6. 이용자의 권리

  • 열람 — 본인의 게임 데이터 확인 (!내정보 명령어로 즉시 확인 가능)
  • 삭제 — 본인 데이터의 삭제 요청 (운영자가 처리)
  • 정정·문의 — 데이터 오류 정정 및 처리 관련 문의
데이터 삭제·열람·정정 요청은 아래 문의처로 연락해 주세요. 본인 확인(디스코드 ID 대조) 후 처리됩니다.

7. 데이터 보안

  • 봇 운영에 필요한 토큰·API 키 등은 코드와 분리된 설정 파일로 관리되며 공개 저장소에 포함되지 않습니다.
  • 다만 본 봇은 개인이 운영하는 비영리 서비스로, 완벽한 보안을 보장할 수 없으며 호스팅·플랫폼 장애로 인한 데이터 손실 가능성이 존재합니다.

8. 아동의 개인정보

  • 본 봇은 디스코드 이용약관에 따른 최소 연령(만 13세 이상, 일부 국가는 그 이상)을 충족하는 사용자를 대상으로 합니다.
  • 최소 연령 미만 사용자의 데이터가 확인되면 즉시 삭제합니다.

9. 방침의 변경

본 방침이 변경될 경우 봇의 공지 채널 또는 본 문서를 통해 고지하며, 변경된 방침은 고지 시점부터 적용됩니다.
